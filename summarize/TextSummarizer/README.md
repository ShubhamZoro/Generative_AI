# 🧠 AI Text Summarizer using T5 Transformer

An intelligent **abstractive text summarization web application** built using the **T5 Transformer model**, **Flask**, and **Hugging Face Transformers**.
This project allows users to input long paragraphs or documents and instantly generate concise, meaningful summaries.

It is designed to demonstrate practical **Natural Language Processing (NLP)** and **Transformer-based text generation** in a real-world application.

---

## 🚀 Features

* ✨ Abstractive text summarization using **T5 Transformer**

* ⚡ Fast inference for paragraph-level text
* 🧹 Clean and simple UI
* 📄 Easy deployment-ready structure
* 🔍 Ideal for long articles, blogs, and reports

---

## 🛠️ Tech Stack

* **Python**
* **FastApi**
* **Hugging Face Transformers**
* **PyTorch**
* **HTML / CSS**
* **Jupyter Notebook**

---

## 🧠 Model Used

This project uses the **T5 Transformer model** for abstractive summarization.

**Model:** `t5-small`
**Task:** Text Summarization
**Framework:** Hugging Face Transformers

T5 is a powerful transformer model capable of generating human-like summaries by understanding context rather than simply extracting sentences.
